# Demo examples

Each `.json` file here is one real answer recorded with an API key. In **▶️ Demo** mode the app
replays it — answer, references, confidence and the real token counts of that run — without a key
and without charging anything.

## Add one

1. Run the app in **⚡ Live** mode with your Anthropic key and ask a question.
2. Under the answer, open **💾 Save this answer as a demo example**.
3. Click **Save to demo/examples/** (when the app runs on your computer) or **Download (JSON)** and put
   the file in this folder.
4. Commit it. The file holds the question, answer, references, confidence, keywords and token counts.
   It never holds your API key.

Good demo questions name a specific law or topic, for example:

- *When must a personal data breach be reported under the GDPR?*
- *What are the transparency obligations for providers of general-purpose AI models under the AI Act?*
- *What are the targets for publicly accessible EV charging points under the AFIR regulation?*
