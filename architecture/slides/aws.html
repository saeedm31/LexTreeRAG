This is how it runs inside a company’s own AWS account, in Stockholm. Staff open the app in a browser. A load balancer receives them; with a domain it adds HTTPS and a sign-in page (Amazon Cognito). The app runs in containers on ECS Fargate, in a private network with no public address. It starts with 1 copy and grows to 3 when busy. It calls Claude through Amazon Bedrock in the same region, with no API key. It reaches EUR-Lex through a NAT gateway. All copies share one law cache on Amazon EFS, and spend per person and per team is kept in DynamoDB. The app image lives in Amazon ECR and the logs go to CloudWatch. All of this is created by Terraform with one command.
