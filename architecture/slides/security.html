Security and data

Built for a company’s rules

Data stays in the EU

Claude runs on Bedrock in Stockholm. AWS says prompts are not shared with the model maker.

No API keys

The app calls Claude with its AWS role. No secrets in the code or in GitHub.

Only the right people

First locked to your IP. Then staff sign in (Cognito, which can link to Entra ID or Okta).

Private servers

The app has no public address. It only takes traffic from the load balancer.

Spending limits

Team budgets in the app, plus an AWS budget email alert for the account.

Fewer outside calls

Gemini is off on AWS. The only outside call is the search on EUR-Lex.

The questions a company’s security team will ask. Where does the data go? To Bedrock in Stockholm, and AWS states it does not share prompts with the model maker. Where are the keys? There are none; the app uses its AWS role. Who can get in? At first only your own IP address; later staff sign in, and that sign-in can be linked to the company’s Microsoft or Okta accounts. The app servers have no public address. Spend is capped per team, with an extra AWS email alert. And Gemini is switched off so questions do not leave AWS; the only outside call is the search on the public EU law site.
