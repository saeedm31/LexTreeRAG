The same code runs in two places. The public demo runs on Streamlit’s free cloud: visitors bring their own key, or replay recorded answers without one. The company setup runs in the customer’s own AWS account in Stockholm. There are no API keys: the app uses its AWS role to call Claude through Amazon Bedrock. Spend and budgets live on the server, per person and per team. One setting, LLM_PROVIDER=bedrock, switches between the two. On AWS the default answer model is Claude Opus 5.5, because Bedrock’s newer endpoint does not offer Opus 4.6.
