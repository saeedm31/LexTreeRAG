Shipping and running

Ship with a push, set up with one command

1. You push code

to the aws branch on GitHub

2. GitHub checks

Tests run, then the app image is built

3. Image stored

in Amazon ECR, your private image store

4. App updated

ECS swaps in the new version

GitHub signs in to AWS with a short-lived token (OIDC), so no AWS keys are stored in GitHub.

1 command

Shipping a new version is a push. Code goes to the aws branch on GitHub. GitHub runs the tests and builds the app image, stores it in Amazon ECR, and tells AWS to swap in the new version. GitHub signs in to AWS with a short-lived token, so no AWS keys sit in GitHub. The whole setup is written in Terraform: one command creates it in about 15 minutes, and one command removes it. While it runs, the setup costs very roughly 70 to 100 euros a month, mostly the NAT gateway and the load balancer, plus whatever the AI calls cost.
